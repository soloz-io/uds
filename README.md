# UDS Monorepo

Unified Design Stack workspace for shared UI infrastructure.

## Packages

- `packages/ai-design-system` - Existing UI component system (moved as-is)
- `packages/design-schema` - Existing AI schema/registry layer (moved as-is)
- `packages/ui-schema-contracts` - Shared schema contracts used by both layers

## Usage

```bash
pnpm install
pnpm build
pnpm lint
pnpm typecheck
```
